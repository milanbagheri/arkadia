ARCADIA V DEMO — نسخه آنلاین همکاری (Co-op)

این نسخه، بازی تک‌نفره اصلی را حفظ می‌کند و یک لایه اتاق آنلاین به آن اضافه می‌کند.
بازیکنان در یک اتاق، یک دولت/جهان مشترک را با هم مدیریت می‌کنند؛ این نسخه هنوز حالت رقابت PvP با کشورهای جداگانه ندارد.

اجرای محلی:
1) Node.js نسخه 18 یا جدیدتر را نصب کنید.
2) در پوشه پروژه دستور npm install را اجرا کنید.
3) دستور npm start را اجرا کنید.
4) در مرورگر آدرس http://localhost:3000 را باز کنید.
5) یک نفر «ساخت اتاق جدید» را بزند؛ کد را برای دوستش بفرستد.
6) دوستش همان آدرس را باز کند و با کد وارد شود.

انتشار روی اینترنت با Render:
1) کل پوشه arcadia_online را در یک مخزن GitHub قرار دهید.
2) در Render یک Web Service جدید از همان مخزن بسازید.
3) Build Command: npm install
4) Start Command: npm start
5) پس از Deploy، لینک HTTPS سایت را برای هر دو بازیکن بفرستید.

نکته‌ها:
- سرور فعلاً وضعیت اتاق‌ها را در حافظه نگه می‌دارد؛ با Restart سرور، اتاق‌ها پاک می‌شوند.
- برای نسخه آزمایشی و دوستانه طراحی شده است؛ هنوز ورود با حساب کاربری، ذخیره دائمی ابری، ضدتقلب و مدیریت تعارض هم‌زمان ندارد.
- هر بازیکن در این نسخه به یک دولت مشترک دسترسی دارد. برای PvP واقعی (هر بازیکن کشور جدا و نوبت‌های مستقل) باید منطق اصلی بازی بازطراحی شود.
